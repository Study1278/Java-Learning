# Java Practice

Java programs I wrote while learning, organized by topic.

## Folders (inside `src/`)

| Folder | Contents |
|--------|----------|
| `basics/` | Hello World, comments, input, swap two numbers, simple calculator |
| `conditions/` | if, if-else, nested if-else, switch, largest number, leap year |
| `loops/` | for, while, do-while, break, continue, multiplication table |
| `numbers/` | Divisors, count digits, factorial, Fibonacci, GCD, LCM |
| `patterns/` | Star, number and pyramid patterns |
| `methods/` | Methods, local variables, passing parameters |
| `arrays/` | Array introduction |

## Run

```bash
cd src/basics
javac HelloWorld.java
java HelloWorld
```

Or open the project in IntelliJ IDEA and run any file.
