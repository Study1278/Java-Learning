Java Learning 📘

A collection of small Java programs written while learning core Java concepts as a CSE student — covering input handling, conditionals, and control flow basics.

🧠 Topics Covered
Taking user input with Scanner (nextInt(), nextFloat(), next())
if-else and nested if-else statements
switch-case statements
Logical operators (&&, ||)
Basic conditional logic problems (leap year, largest number, even/odd)
Variable swapping
▶️ How to Run

Each file has its own main method and can be run independently.

Using IntelliJ IDEA:

Open the project.
Right-click the file you want to run (e.g. LeapYear.java) → Run.

Using the command line:

powershell
cd src
javac LeapYear.java
java LeapYear
